# 🌾 Sistem Informasi Pertanian (Java Desktop)

Aplikasi desktop untuk pencatatan dan pengelolaan data hasil dan aktivitas pertanian berbasis Java Swing.

### 🛠️ Fitur & Tech Stack
- **Bahasa**: Java (JDK 8/11)
- **UI**: Java Swing (NetBeans GUI Builder)
- **Database**: MySQL
- **Laporan**: JasperReports / iReport
